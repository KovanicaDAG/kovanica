# SESSION-LOG — continuity log

One row per session, newest on top. Feeds the learning loop: lessons worth
keeping forever go to the universal memory ledger; project-specific ones
stay here or in KNOWN-TRAPS.

| Date | Goal | Shipped | Verified how | Follow-ups |
|------|------|---------|--------------|------------|
| YYYY-MM-DD | <one line> | <commits/PRs> | <tests/commands run> | <what's next> |

## Conventions

- `Goal` = what this session set out to do (one line)
- `Shipped` = links to commits/PRs — *shipped*, not "worked on"
- Empty row cells are a smell: either the session had no goal or nothing shipped
